# Jason Games Launcher

Download the [latest launcher release](https://github.com/Crybb227/AA-Emu-Launcher/releases/latest),
extract the portable ZIP, and run **Start Launcher.bat**.

JasonHawkSkater installs and runs natively on Windows x64 from the normal launcher
game section. Its server must be started externally through the Discord helper.
See the [player and publisher guide](docs/jason-hawk-skater.md) for installation,
assets, keyboard/controller controls, updates, and testing limitations.
